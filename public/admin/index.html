Jeton GitHub :

Lire les contenus ne demande rien. Pour enregistrer, il faut un jeton GitHub qui autorise l'écriture dans le dépôt du site. À créer une fois :

  1. Ouvrir github.com/settings/personal-access-tokens/new.
  2. « Repository access » : « Only select repositories », puis choisir le dépôt du site.
  3. « Permissions », « Repository permissions » : « Contents » sur « Read and write ».
  4. Générer le jeton, le copier et le coller ci-dessous.

Le jeton reste dans ce navigateur, sur cet appareil. Il n'est envoyé qu'à GitHub.
